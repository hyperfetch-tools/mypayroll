# MyPayroll Statutory Doctor — Malaysia KWSP, PERKESO ASSIST, LHDN CP39 & Bulk Salary Converter

Live Web App: **https://hyperfetch-tools.github.io/mypayroll/**

Convert monthly SME salary Excel/CSV sheets into all **4 Malaysian statutory & bank upload files** in 15 seconds—with **zero monthly per-employee fees** and **zero database storage (PDPA-safe stateless RAM)**:

1. **KWSP (EPF) i-Akaun Employer `.CSV`** — Automatic Contribution Month (`Wage Month + 1`), KWSP Third Schedule + mandatory **2% Foreign Worker EPF**, and leading-zero MyKad/KWSP member number restoration.
2. **PERKESO ASSIST Combined 244-Byte Fixed-Width `.TXT`** — Unified SOCSO (Act 4) + EIS (Act 800) + SKBBK integer-cent format with RM 6,000 ceiling, Category 1 vs Age 60+ Category 2 routing, and Foreign Worker EIS exemption.
3. **LHDN e-Data PCB / e-PCB Plus (`CP39`) `.TXT`** — Exact 57-byte Header (`H`) + 136-byte Detail (`D`) records with automatic `IG` TIN normalization.
4. **Malaysian Bank Bulk Salary `.CSV`** — Automatic Net Pay calculation + 8-character SWIFT/DuitNow BIC lookup (`MBBEMYKL`, `CIBBMYKL`, `PBBEMYKL`, `RHBBMYKL`, `GXSPMYKL`, etc.).
